# 夹爪 MIT 通信适配

当前 `bxi_motor_source.zip` 中的 `USE_ENC2=0` 夹爪固件使用以下 MIT 物理量：

- 位置：`0..90 mm`；固件内部将机械行程限制为约 `0..80.55 mm`。
- 速度：`-641..641 mm/s`，由固件 `max_vel=45 rad/s` 和 `89.5 mm/turn` 换算。
- 力矩字段：夹持力，50 型为约 `-16..16 N`，50L 型为约 `-24..24 N`。
- `Kp`：`0..5`；`Kd`：`0..5`。

夹爪接收帧时，固件将力值换算为电机侧力矩，再使用 `KT=0.07 N·m/A` 换算为
q 轴电流。50L 夹爪默认电流限幅约 `4.889 A`，对应约 `24 N` 的通信力值。
回复帧中的力值由 `Foc.i_q_filt * KT * HAND_FORCE_PER_TORQUE_N` 计算。

上位机中的 `50_hand` 和 `50L_hand` 配置按上述范围打包和解析；`stand_up` 发送
回零增益时会按每个电机型号的 `Kp/Kd` 范围限幅。

源码包只包含固件源码和构建脚本，没有附带新的 `.bin` 文件。要使用源码中修正
的夹爪力矩换算，需要用该源码重新构建 `hand/50L` 固件后，再替换项目固件目录
中的 `firmware/bxi_motor_50L_hand.bin`。
